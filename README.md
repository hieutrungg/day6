# React Hooks Todo List

Ứng dụng Todo List đơn giản minh họa các React Hook phổ biến:

- `useState`: quản lý ô nhập.
- `useReducer`: quản lý danh sách công việc.
- `useEffect`: đồng bộ dữ liệu với `localStorage`.
- `useRef`: tự động focus ô nhập.
- `useMemo`: đếm số việc chưa hoàn thành.
- `useCallback`: ghi nhớ hàm thêm công việc.
- `useContext`: quản lý giao diện sáng/tối.
- Custom Hook `useLocalStorage`: tái sử dụng logic lưu dữ liệu.

## Chạy project

```bash
npm install
npm start
```

## Kiểm tra

```bash
npm test -- --watchAll=false
```
